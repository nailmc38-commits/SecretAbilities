# Mini Game Hub

Fabric 1.21.11 client-side mod.

Press **F9** to open a game hub inside Minecraft.

Included games:
- **Mini Minecraft 3D** — a tiny first-person voxel sandbox with terrain, trees, caves, mining, placing, inventory blocks, jumping and mouse-look. The style is intentionally simple and old-school/1.8-like.
- **Block Drop / Tetris-style** — 10x20 falling-block arcade game with rotation, line clears, scoring and hard drop.
- **Neon Maze 3D** — raycast 3D maze. Collect three energy cores and find the exit.
- **Wasteland: Third Person** — original post-apocalyptic scavenging game with ruined terrain, radiation, supplies, drones, third-person player view and a bunker objective.

Controls are shown inside each game. F9 or Escape returns from a game to the hub.

This project replaces the previous utility/hacked-client code. There are no X-ray, ESP, movement-hack, anti-cheat, macro, or combat-client modules in this build.

Requirements:
- Minecraft Java 1.21.11
- Fabric Loader 0.18.2+
- Fabric API 0.139.4+1.21.11
- Java 21
