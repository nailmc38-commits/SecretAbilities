# Mini Game Hub 3.0

Fabric 1.21.11 client-side mod. Press **F9** to open the game hub inside Minecraft.

## Hub layout
- **GAMES** tab — 20 playable games across 2 compact pages.
- **PvP PRACTICE** tab — dedicated Anchor PvP training arena.

## Featured games
- **Mini Minecraft: Survival+** — first-person voxel survival with improved jumping/step-up movement, a 9-slot hotbar, larger terrain, water, caves, more trees, animals (pig/cow/chicken/sheep), hunting and meat, health/hunger, day/night, coal/iron ore, furnace, crafting table, sticks, torches, stone/iron tools, smelting, cooking, building and block mining.
- **Cozy Trails** — detailed chill exploration game with 11 biomes, 4 seasons, day/night, rain, snow, mist, lakes/coast, cabins, docks, lighthouse, hot spring, campfire, lantern, map, journal, fishing, foraging, collectibles, butterflies, fireflies and 12 discoverable places.
- **Block Drop Deluxe** — upgraded falling-block game with hold piece, next preview, ghost piece, hard/soft drop, levels, line scoring, pause and faster difficulty.
- **Neon Maze 3D** — raycast 3D maze with energy cores and an exit objective.
- **Wasteland Terminal** — text-only original wasteland RPG with choices, exploration, scavenging, supplies, radiation, encounters and a bunker-code objective.

## Other games
Snake, Pong, Breakout, Asteroids, Space Invaders, Flappy Block, 2048, Minesweeper, Memory Match, Sokoban, Frogger, Platformer, Neon Racing, Tower Defense and Dungeon Crawler.

## Anchor PvP Practice
Open **F9 → PvP PRACTICE → Anchor PvP Practice**.
- Walk: WASD
- Jump: Space
- Sprint: Ctrl
- **Z** = select anchor
- **X** = select glowstone
- **Right click** = place / charge / explode
- Explosions destroy the practice terrain while reusable obsidian pads stay available.
- Practice player takes **zero self-damage**.
- **R** resets the arena.

Controls are shown inside each game. **F9** or **Escape** returns to the hub.

Requirements:
- Minecraft Java 1.21.11
- Fabric Loader 0.18.2+
- Fabric API 0.139.4+1.21.11
- Java 21
