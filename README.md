# Mini Game Hub 2.0

Fabric 1.21.11 client-side mod. Press **F9** to open a game hub inside Minecraft.

## 19 playable games

### Featured
- **Mini Minecraft: Survival** — tiny first-person voxel survival game with generated terrain, trees and caves; 9-slot hotbar; mining time; block placing; health; hunger; apples; fall damage; day/night lighting; basic crafting; mouse-look; jumping and sprinting.
- **Block Drop / Tetris-style** — falling-block arcade game with rotation, line clears, score and hard drop.
- **Neon Maze 3D** — raycast 3D maze with energy cores and an exit objective.
- **Wasteland Terminal** — text-only original wasteland RPG with choices, exploration, scavenging, supplies, radiation, encounters and a bunker-code objective.

Controls are shown inside each game. **R** restarts most games. **F9** or **Escape** returns to the hub.

This project contains no X-ray, ESP, movement-hack, anti-cheat, macro, or combat-client modules.

Requirements:
- Minecraft Java 1.21.11
- Fabric Loader 0.18.2+
- Fabric API 0.139.4+1.21.11
- Java 21
